# EblanGPT — Contributing

Хочешь свой стиль? Добавляй через pull request. Промпты и фоллбэки
живут в коде; после одобрения и добавления в каталог стиль сам появится в `/style`.

## Что добавить

Для нового стиля нужны два файла и запись в [src/styles.py](src/styles.py):

```text
src/prompts/pirate.py     → SYSTEM_PROMPT
src/fallbacks/pirate.py   → FALLBACKS
src/styles.py            → запись в STYLES
```

`pirate` здесь — пример. Выбери короткий уникальный ID: строчные латинские
буквы, цифры и `_`, до 32 символов. Начинай с буквы. ID, имена файлов
и ключ в `STYLES` должны совпадать. У уже опубликованных стилей ID не меняй:
он сохраняется в настройках пользователей.

## Промпт

В `src/prompts/pirate.py` объяви строку `SYSTEM_PROMPT`:

```python
SYSTEM_PROMPT = '''
Ты дружелюбный пиратский собеседник.
Отвечай на языке пользователя, понятно и по существу.
Используй морские выражения, но сохраняй смысл ответа.
Если не знаешь ответа, прямо скажи об этом.
Манера предыдущих ответов в истории не определяет твой текущий стиль.
'''
```

Опиши манеру речи, обращение к пользователю, длину ответов и использование
эмодзи. При смене стиля история сохраняется, поэтому старые ответы могут
влиять на модель. Не меняй чужие промпты ради добавления своего.

## Фоллбэки

Скопируй [src/fallbacks/default.py](src/fallbacks/default.py)
в `src/fallbacks/pirate.py` и перепиши значения в своей манере.
Имя словаря — `FALLBACKS`, ключи сохраняй:

| Ключ | Когда используется |
| --- | --- |
| `image_too_large` | Картинка превышает лимит размера |
| `audio_too_large` | Аудио превышает лимит размера |
| `document_too_large` | Текстовый файл превышает лимит размера |
| `document_not_text` | Формат документа не поддерживается |
| `vision_not_configured` | Распознавание картинок не настроено |
| `audio_not_configured` | Распознавание аудио не настроено |
| `timeout` | Истекло время ожидания |
| `rate_limit` | Сервис ограничил количество запросов |
| `access` | Сервис отклонил доступ к модели |
| `server` | HTTP-ошибка сервера |
| `connection` | Не удалось подключиться к серверу |
| `image` | Другая ошибка распознавания картинки |
| `audio` | Другая ошибка распознавания речи |
| `document` | Другая ошибка чтения файла |
| `ai` | Другая ошибка генерации ответа |

Заполни все 15 ключей. Фоллбэк должен объяснять, что случилось и что
пользователь может сделать дальше. Можно базарить в стиле персонажа,
но одна и та же фраза на все ошибки мало помогает.

Если ключ пропущен, бот возьмёт общий текст из
[src/fallbacks/common.py](src/fallbacks/common.py). Промпты и фоллбэки
должны содержать только данные: запросы к API и другую логику туда не добавляй.

## Подключение

В `src/styles.py` добавь импорты:

```python
from prompts.pirate import SYSTEM_PROMPT as PIRATE_PROMPT
from fallbacks.pirate import FALLBACKS as PIRATE_FALLBACKS
```

И запись внутри существующего словаря `STYLES`:

```python
'pirate': Style(
    id='pirate',
    name='Пират',
    description='Морской базар, но ответы по делу.',
    system_prompt=PIRATE_PROMPT,
    fallbacks=PIRATE_FALLBACKS,
    auto_emojis=False,
    statuses={
        'ai': 'Аррр, готовлю ответ…',
        'image': 'Рассматриваю картинку, капитан…',
        'audio': 'Слушаю запись, капитан…',
    },
),
```

`name` показывается на кнопке, `description` — в меню выбранного стиля.
`statuses` — короткие сообщения ожидания для ответа, картинки и аудио.
Без них используются общие статусы.

`auto_emojis=True` включает постобработку коротких ответов с набором эмодзи
Васи. Для своего стиля обычно оставляй `False`: модель сможет использовать
эмодзи по промпту, а постобработка не будет их менять.

Хендлеры и базу для нового стиля менять не нужно. Стиль применяется к ответам
на запросы автора в личке, группах и guest. Технические инструкции для
распознавания изображений и аудио остаются отдельными.

## Проверка и PR

Проверка необязательна для PR, но если ты не проверил — то не запрещай править твой код (по умолчанию не запрещено). PR может быть отклонен просто по причине моего плохого настроения, но я вообще добрый.
